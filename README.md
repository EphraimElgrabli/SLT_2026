
# יומן התקדמות

**תאריך:** 08.05.2026

זהו יומן ההתקדמות הנוכחי של פרויקט השחזור שלנו למאמר **Depth Anything V2**. בשלב הזה סיימנו את שלב ההקמה, הכנת `DA-2K`, והרצת השחזור הראשונה בפועל על שלושת מודלי הסטודנט הציבוריים של המאמר. בנוסף, כבר הורדנו את `KITTI` ואת `NYU-Depth-v2` כדי להכין את הקרקע לשלב הבא של הערכה מטרית.

עד עכשיו ביצענו את הדברים הבאים:

- סידרנו את מבנה הפרויקט כך שיהיה ברור ונקי, עם תיקיית `data` מסודרת עבור מודלים, דאטה, פלטים וסקריפטים.
- הוספנו תהליך bootstrap מסודר שמקים סביבת עבודה מקומית לפרויקט.
- חיברנו את הפרויקט למימוש הרשמי של `Depth Anything V2` מתוך המאגר הרשמי.
- קיבענו גרסה ברורה של הקוד החיצוני כדי שהשחזור יהיה עקבי ולא ישתנה בין הרצות.
- הקמנו סביבת `Python` מקומית והתקנו את כל התלויות הנדרשות.
- הרחבנו את תהליך ההורדה כך שהוא תומך בשלושת ה־checkpoints הציבוריים של מודלי הסטודנט: `vits`, `vitb` ו־`vitl`.
- הרצנו בדיקת sanity check על תמונות הדוגמה של הפרויקט, וההרצה הושלמה בהצלחה עם פלטים שנשמרו בתיקיית `data/outputs/sanity_check`.
- הורדנו את benchmark `DA-2K` מתוך Hugging Face ושמרנו אותו בצורה מסודרת תחת `data/datasets/da2k`.
- חילצנו את הדאטה, אימתנו את קובץ ההערות (`annotations.json`), ובנינו תהליך preprocessing מסודר להמשך העבודה.
- יצרנו קבצי manifest וסטטיסטיקות שמרכזים את הדאטה בפורמט נוח להערכה.
- נכון לעכשיו יש אצלנו עיבוד תקין של `1033` תמונות עם `2068` זוגות השוואה יחסית לעומק.
- בנוסף, טיפלנו גם באי־התאמה אחת בשם קובץ בתוך הדאטה, כדי שתהליך ההכנה יהיה יציב ולא יקרוס בהרצה.
- מימשנו pipeline הערכה עבור `DA-2K`, כולל הרצה חוזרת בטוחה, שמירת תחזיות לכל זוג נקודות, וחישוב accuracy כללי ולפי סוג סצנה.
- הרצנו את שלושת המודלים הציבוריים על `DA-2K` והשווינו את התוצאות לערכים שמופיעים במאמר.
- התוצאות משחזרות את טבלת המאמר בצורה קרובה מאוד: `ViT-S` קיבל `95.16%` לעומת `95.30%` במאמר, `ViT-B` קיבל `97.05%` לעומת `97.00%`, ו־`ViT-L` קיבל `97.10%` לעומת `97.10%`.
- יצרנו דו"ח שחזור מסודר: `reports/da2k_reproduction.docx`.
- יצרנו קובץ hashes עבור ה־checkpoints, קבצי התחזיות וסיכום התוצאות: `reports/da2k_artifact_hashes.txt`.
- הוספנו תהליך מסודר להורדת כל ה־benchmarks הנוספים: `KITTI`, `NYU-Depth-v2`, `Sintel`, `ETH3D` ו־`DIODE`.
- מתוך הרשימה הזו הצלחנו להוריד בפועל את `KITTI` ואת `NYU-Depth-v2` ולשמור אותם בתיקיות ייעודיות תחת `data/datasets`.
- במהלך ההורדה של שאר המאגרים עלתה מגבלת מקום פנוי בדיסק, ולכן עצרנו את ההורדות לפני יצירת קבצים חלקיים מיותרים.
- בעקבות זה חיזקנו את סקריפט ההורדה כך שהוא בודק מראש מקום פנוי בדיסק ועוצר עם הודעה ברורה לפני התחלת הורדה שלא תוכל להסתיים.
- בנוסף, יצרנו מצגות התקדמות שמסכמות את הבעיה, שיטת המאמר, הדאטה, ותוכנית השחזור.

במילים פשוטות, שלב `DA-2K` כבר הושלם: יש דאטה מעובד, קוד הערכה, תוצאות מספריות, השוואה מול המאמר, דו"ח שחזור, ו־hashes שמאפשרים לוודא שהתוצרים לא נערכו ידנית. `KITTI` ו־`NYU-Depth-v2` כבר קיימים מקומית, אבל הם שייכים לשלב הבא: הערכה מטרית עם מדדים כמו `AbsRel`, `RMSE` ו־`delta1`.

## איך לשחזר את שלב DA-2K

הרצה מלאה של שלב `DA-2K` מתבצעת דרך נקודת הכניסה המרכזית:

```bash
python data/scripts/slt_data.py setup
python data/scripts/slt_data.py da2k
python data/scripts/slt_data.py evaluate-da2k
python data/scripts/python/build_da2k_report.py
```

התוצרים המרכזיים הם:

- `data/outputs/da2k/predictions/*.jsonl` - תחזיות לכל זוג נקודות ולכל מודל.
- `data/outputs/da2k/summary.json` - סיכום accuracy כללי ולפי סצנה.
- `reports/da2k_reproduction.docx` - דו"ח שחזור מסודר.
- `reports/da2k_artifact_hashes.txt` - hashes מלאים של התוצרים.

## הצעד הבא

השלב הבא כבר איננו `DA-2K`; הוא הרחבת השחזור לבנצ'מרקים מטריים. העבודה המומלצת לשלב הבא היא:

- להכין preprocessing עבור `KITTI` ו־`NYU-Depth-v2`, שכבר הורדו למכונה.
- לממש מדדי עומק מטריים כמו `AbsRel`, `RMSE` ו־`delta1`.
- לוודא crop, valid-mask, scale/shift alignment וכללי evaluation שמתאימים להשוואה הוגנת מול המאמר.
- להריץ baseline ראשון על `KITTI` ו־`NYU-Depth-v2`.
- להשלים הורדה של `Sintel`, `ETH3D` ו־`DIODE` אחרי פינוי מקום בדיסק.

זהו הבסיס שממנו נוכל להכין את שקופית ההתקדמות הבאה בצורה אמינה ומדויקת: שלב ראשון הושלם, והשלב הבא הוא מעבר מ־relative depth ב־`DA-2K` אל metric depth בבנצ'מרקים הוותיקים.
