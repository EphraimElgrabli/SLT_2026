
# יומן התקדמות

**תאריך:** 12.04.2026

זהו יומן ההתקדמות הנוכחי של פרויקט השחזור שלנו למאמר **Depth Anything V2**. בשלב הזה התמקדנו בהקמה מסודרת של סביבת העבודה, כדי שנוכל לעבור בהמשך לוולידציה אמיתית על ה־benchmarks של המאמר.
זהו יומן ההתקדמות הנוכחי של פרויקט השחזור שלנו למאמר **Depth Anything V2**. בשלב הזה סיימנו את שלב ההקמה הראשוני, והתקדמנו גם להכנת הדאטה עבור ה־benchmark הראשון.

עד עכשיו ביצענו את הדברים הבאים:

- סידרנו את מבנה הפרויקט כך שיהיה ברור ונקי, עם תיקיית `data` מסודרת עבור מודלים, דאטה, פלטים וסקריפטים.
- הוספנו תהליך bootstrap מסודר שמקים סביבת עבודה מקומית לפרויקט.
- חיברנו את הפרויקט למימוש הרשמי של `Depth Anything V2` מתוך המאגר הרשמי.
- קיבענו גרסה ברורה של הקוד החיצוני כדי שהשחזור יהיה עקבי ולא ישתנה בין הרצות.
- הקמנו סביבת `Python` מקומית והתקנו את כל התלויות הנדרשות.
- הורדנו את מודל ה־checkpoint הקטן לצורך בדיקת תקינות ראשונית.
- הרצנו בדיקת sanity check על תמונות הדוגמה של הפרויקט, וההרצה הושלמה בהצלחה עם פלטים שנשמרו בתיקיית `data/outputs/sanity_check`.
- הורדנו את benchmark `DA-2K` מתוך Hugging Face ושמרנו אותו בצורה מסודרת תחת `data/datasets/da2k`.
- חילצנו את הדאטה, אימתנו את קובץ ההערות (`annotations.json`), ובנינו תהליך preprocessing מסודר להמשך העבודה.
- יצרנו קבצי manifest וסטטיסטיקות שמרכזים את הדאטה בפורמט נוח להערכה.
- נכון לעכשיו יש אצלנו עיבוד תקין של `1033` תמונות עם `2068` זוגות השוואה יחסית לעומק.
- בנוסף, טיפלנו גם באי־התאמה אחת בשם קובץ בתוך הדאטה, כדי שתהליך ההכנה יהיה יציב ולא יקרוס בהרצה.

במילים פשוטות, סיימנו את שלב ההקמה הראשוני, ואנחנו גם יודעים שה־dataset הראשון מוכן לעבודה בצורה מסודרת.

## הצעד הבא

השלב הבא הוא להתחיל את עבודת הוולידציה עצמה על בסיס מה שכבר הכנו:

- לממש או לאמת את המטריקות
- להריץ הערכה ראשונה על benchmark אחד
- להשוות את התוצאות לערכים שמופיעים במאמר

זהו הבסיס שממנו נוכל להכין את שקופית ההתקדמות הבאה בצורה אמינה ומדויקת.
